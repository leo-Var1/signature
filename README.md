# Signature mail de Léo Varain

Images de ma signature Gmail, servies par GitHub Pages : https://leo-var1.github.io/signature/

## Installer la signature

1. Ouvrir https://leo-var1.github.io/signature/
2. Ctrl+A puis Ctrl+C.
3. Gmail : Paramètres, Voir tous les paramètres, Général, Signature ; coller (Ctrl+V), puis enregistrer en bas de la page.

## Contenu

- `entete.png` : nom et portrait, fixe, 560 x 200 affiché (fichier en double résolution).
- `stage.gif` : la ligne de stage, qui s'écrit une fois puis reste affichée.
- `picto-*.png` : pictos du téléphone, de LinkedIn et du site.
- `index.html` : la signature, à copier-coller dans Gmail.

Les sources (gabarits HTML et script de capture) sont dans le dépôt job-search, `build/signature/`.
Plus tard, ces images passeront sur leovarain.fr.
